# STAT 184 

## About 
This repository contains a reproducible data analysis completed as part of STAT 184 
at Penn State University. The analysis covers three topics: airport passenger traffic 
trends, Monte Carlo numerical integration, and a comparison of AI prompting strategies 
using a calcium dataset.

## Data 
- Airport passenger traffic data: manually compiled from publicly available 
  aviation industry reports for the years 2020–2024.
- Calcium dataset: a study tracking 31 women over 4 years measuring 
   calcium levels across two treatment groups.
- GenAI comparison plots: generated using Claude Sonnet 4.6 via claude.ai.
